# Network Command Center

PWA preview for the owner's GX Titanium T21 Pro (Titanium-2122A), firmware T2122-V1.28, hardware C40-210, gateway 192.168.1.1. Four DHCP clients captured from router screenshots.

This is a frontend preview only. It does not include server authentication or a live router connector. Do not publish private network data as a protected product until real authentication, API authorization, and rate limiting are implemented. Never commit router admin credentials or expose the router management interface publicly.

Install on iPhone after HTTPS hosting: Safari Share -> Add to Home Screen.
