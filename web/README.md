# Network Command Center

This is a PWA preview built from the GX Titanium T21 Pro (Titanium-2122A) screenshots supplied by the owner.

- Gateway IP: 192.168.1.1
- Firmware: T2122-V1.28
- Hardware: C40-210
- Wi-Fi bands: 2.4 GHz channel 12; 5 GHz channel 52
- DHCP snapshot includes four client rows.

The preview does not yet have a real authentication service or router connector. Do not publish sensitive network data to this branch until authentication and API authorization are implemented. Never put router admin credentials in frontend code or GitHub.

Install on iPhone after HTTPS hosting: Safari Share -> Add to Home Screen.
